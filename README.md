# Poke'Catch 挂机助手 · AutoFarm

面向 [Poke'Catch Online](https://pokecatch-online.netlify.app/) 的用户脚本，提供挂机辅助、进度监控、存档备份与提醒功能。当前版本：**3.6.0**。

## 功能

- 自动处理捕获图鉴卡、普通确认框、礼物选择和进化过场；仅对安全白名单操作，遇到放生、出售、删除、重置等危险操作时不会自动点击。
- 自动进入游戏、保持游戏速度、定时保存，并在检测到新闪光、活动、徽章、停滞等事件时提醒。
- 显示章节进度、捕获/战斗/金钱速率、队伍状态和事件日志；提供队伍建议与宝可梦评分角标。
- 可自动维持树果增益、切换残血队员、运行游戏城自动模式。残血自动换人和游戏城自动模式默认关闭；游戏城模式会消耗游戏内金钱。
- 定期备份和恢复游戏存档，统计离开期间收益，并支持 Bark、ntfy、Telegram 推送。
- 提供昼夜提示、夜间零捕获检查、停滞检测、屏幕常亮及可选后台保活。

真实鼠标或键盘操作时，脚本会暂时让出控制权。后台标签页可能被浏览器节流，自动化速度会下降；屏幕常亮和后台保活也无法保证浏览器或设备持续运行。

## 安装

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 打开本仓库中的 [`pokecatch-autofarm.user.js`](./pokecatch-autofarm.user.js)，将源码导入用户脚本管理器并保存。
3. 访问 [Poke'Catch Online](https://pokecatch-online.netlify.app/) 或 [Pages 镜像](https://pokecatch-online.pages.dev/)。页面右上角出现挂机面板即表示脚本已运行。
4. 在面板中打开设置，按需调整自动化功能。

脚本匹配以下地址：

```text
https://pokecatch-online.netlify.app/*
https://pokecatch-online.pages.dev/*
```

## 使用说明

- 面板可拖动、折叠；支持暂停、诊断和队伍建议。
- `Alt + P`：暂停或继续自动化。
- `Alt + H`：显示或隐藏面板。
- 自动刷新默认关闭。启用前建议先使用停滞提醒，以免页面刷新打断游戏流程。
- 推送功能需要在设置中填写对应服务的地址或凭据。推送密钥存放在用户脚本管理器存储中。
- 存档备份同样保存在用户脚本管理器存储中。卸载脚本或清除管理器数据前，请先导出重要备份。

## 隐私与存储

- 游戏存档键：`gachamon-save-v1`。脚本会读取此存档以展示统计、检测事件及执行用户启用的存档操作。
- 脚本配置：`localStorage['pcauto.cfg.v1']`。
- 闪光记录：`localStorage['pcauto.shinies.v1']`。
- 自动备份及推送凭据使用 Tampermonkey / Violentmonkey 提供的 GM 存储。
- 启用推送后，脚本会向所选推送服务发送已启用的事件通知；请只配置自己信任的服务。

## 权限

脚本通过 GM 存储 API 保存设置之外的私密数据，并通过 GM 网络请求 API 向 `api.day.app`、`ntfy.sh` 或 `api.telegram.org` 发送推送。元数据还声明了通用网络连接权限，以支持推送服务地址配置。

## 故障排查

- 确认脚本已启用，并且当前页面地址匹配上面的两个域名。
- 如果面板提示页面停滞，先确认游戏页面在前台运行；后台标签页受浏览器节流时可能无法满速推进。
- 如果游戏不再继续，检查是否出现脚本无法安全识别的弹窗。危险操作和未知按钮需要由玩家手动处理。
- 推送未送达时，检查服务地址、令牌及对应事件开关。

## 版本

脚本元数据和源码常量中的版本均为 `3.6.0`。升级时请在用户脚本管理器中更新脚本内容。
